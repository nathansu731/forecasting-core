# Forecast Navigator

## Purpose
Forecast Navigator helps users inspect forecast output by SKU and store and compare historical demand with forecasted periods.

## Assistant Guidance
If the user asks why a series looks unusual, the assistant should prefer series-specific facts from artifacts. If only aggregate run metrics are available, it should say the explanation is partial.

## Multi Store Behavior
Where more than one store exists, the assistant should refer to SKU and store together, not just SKU, because demand and risk can differ by location.
