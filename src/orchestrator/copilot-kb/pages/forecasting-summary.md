# Forecasting Summary

## Purpose
Forecasting Summary is the high-level run review page. It should summarize the selected run, model choice, validation quality, and major forecast outcomes.

## Assistant Guidance
The assistant should use run summary artifacts to explain what model ran, what mode was used, how many series were processed, and what the main validation results mean. It should not pretend this page is where edits are made.

## Caveats
If validation is based on holdout windows or a limited set of series, the assistant should mention that scope so users do not overgeneralize the numbers.
